# Mechanisms of Action (MoA) Drug Prediction

## Overview
Predicting biological mechanisms of action (MoA) of drug compounds based on gene expression and cell viability responses. Dataset provided by the Harvard Laboratory for Innovation Science (LISH) and the Broad Institute.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
